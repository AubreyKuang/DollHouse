# 像素小屋 · DollHouse · 游戏策划案

**版本** 0.1 · **更新** 2026-11-13 · [功能](#feature-index) · [设计决定](#decisions) · [更新记录](#change-log)

## 游戏概述

玩家布置房子、安排住户相处，再观察他们如何上班、来往和照顾彼此。每个游戏月以月报收束，下一月接着同一个家和同一批人的生活。扩建是长期选择，游戏可以持续观察和布置。

- 侧视像素生活模拟 · 网页 · 鼠标与触屏 · JavaScript / Canvas / Web Audio
- [ASSUMPTION] 目标玩家为喜欢布置、观察住户关系和短时回访的休闲玩家。

## 设计支柱

- 家具能改变住户的行动和相遇地点。
- 主动安排之后，住户亲自到场、行动并作出回应。
- 小屋允许安静地过日子，月报把值得回看的事留下来。

## 核心循环

观察作息和需求 → 摆家具或安排相处 → 看住户实际行动 → 从相册或月报回看 → 调整下个月的安排。

## 首轮试玩

新档从 08:00 开始。第一次主动操作用场景下方的头像选中一位住户，再选一件可达的家具，亲眼看他走过去并开始使用。观察玩家是否能在住户外出或家具占用时自行换人或换目标。
