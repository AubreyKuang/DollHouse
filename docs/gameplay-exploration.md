# DollHouse的玩法探索

观察住户自主生活。布置改变他们相遇的机会，沿用现有家具、操作和存档。

## 已实现的试玩版本

| 试玩 ID | 玩家目标和反复选择 | 状态、进展与代价 | 依据与最小试玩 |
| --- | --- | --- | --- |
| DH-01a（DH-01；空间变化带来主动靠近） | 想让谁自然碰面？调整熟悉的阅读角，观察后再调整。 | 实时模拟 · 放置 → 房间邻接 · 住户自行选活动 · 实际同坐恢复社交，每角每月一次 · 占地方，也受可达性、友好和作息限制。 | 源码已有熟客、寻路和房间。两张并排时能引起额外吸引，隔开则没有。未知：自然发生得够不够频繁？从有两处老地方的存档各跑一晚，换位置后比较玩家有没有看见差别。 |

人工试玩待进行。下面的判断来自源码和规则推演。

## 探索过的方向

| ID | 读取的状态 → 反复做的选择 | 进展、代价与熟练策略 | 初筛 |
| --- | --- | --- | --- |
| DH-01 | 房间、谁常坐哪里 → 拉近两张熟悉的座位或分开 | 促成自然相遇 / 占用合适的地块 / 看谁同时在家 | 留下，改成 DH-01a |
| DH-02 | 楼梯、门口人流 → 把客厅家具摆在通路附近或避开 | 改变碰面 / 经过的人会打扰 / 判断动线 | 待测；路径之外的打扰还没建模 |
| DH-03 | 住户作息、家具空闲 → 预留设施给晚归的人 | 解决撞时间 / 白天少一件可用家具 / 预留前看回家时间 | 待测；可能变成排班 |
| DH-04 | 个性和空房 → 给住户安排安静区或共享区 | 形成生活偏好 / 空间有限 / 平衡独处与交流 | 待测；需要先定义独处收益 |
| DH-05 | 邻近座位与住户关系 → 把两个阅读点换成两处茶座 | 同样靠邻近提高相遇率 / 同样占地 / 同样看作息 | 与 DH-01 重复 |
