平台：TapTap H5 小游戏，竖屏，开放试玩，免费，无内购，单机，不接 TapTap 登录，不联网。V1.0.0（线上）没有广告；V1.0.1 留好了一个激励视频广告位，见文末「广告」。

## 为 TapTap 做的改动

- **存档回退**（`js/house-storage.js`）：依次试 `tap.setStorageSync` → localStorage → 只在本次游玩中保留，每一种都先写入、读回一致才用。`tap` 存储按 20 万字符分块，单个 key 不超过 1MB，新数据写完才换清单，写一半失败时旧存档不受影响；分块不会把 emoji 拆成两半。第一次在 TapTap 里打开时，会把浏览器里留下的小屋带过来一次。
- **为什么没有 IndexedDB**：小屋在启动时同步读档，每 5 秒同步存档，`SaveManager` 还靠同步读取判断别的标签页有没有改过进度。IndexedDB 只有异步接口，这里不用，和《浮梦之境》的设置与续航点一样。
- **都存不了时**：照样能玩，开局约 1.5 秒后提示一次「当前环境无法保存进度，本次游玩中仍可继续」；菜单里的存档按钮显示「⚠️ 无法保存，下载备份」，存档面板也会说明。
- 游戏里原来直接读写 localStorage 的地方（离开时继续、月报自动打开、导入前备份）都改走同一个存储。
- **TapTap 宿主**（`js/taptap.js`）：只检测全局 `tap`，给页面加 `taptap-host` 标记，不调用 `tap.login`，不联网。
- **外部请求**：游戏只用系统字体，画面全部由 Canvas 绘制，没有 CDN、网络字体或远程图片。`tests/taptap-host.test.cjs` 会检查源码里没有 `fetch`、XHR、WebSocket 和外链。

## 定稿文案

- **游戏名：** 像素小屋
- **副标题：** 布置房间，看像素小人自己过日子
- **一句话简介：** 给四位像素小人一间房子，剩下的日子由他们自己过。
- **首页推荐语（21 字）：** 布置小屋，看像素小人自己恋爱、吵架、过日子
- **游戏类型：** 模拟
- **适龄：** 12+（住户会恋爱、吃醋、吵架、分手，没有暴力和付费内容）

**长简介：**

《像素小屋》是一个装在手机里的像素小人之家。四位住户已经住进来了：面包师团子和宅在家的阿懒是一对恋人，阿懒对咖啡师小桃也有点意思，眼镜君一直在暗恋小桃。接下来谁会表白，谁会被撞破，谁和谁成了饭搭子，每一局都不一样。

你不用替他们安排每一件事。他们会自己上班上学、做饭睡觉、弹琴打游戏、聊天交朋友，偶尔吃醋吵架，过一阵也可能和好。你负责布置房间、给他们换衣服；想推一把的时候，先点小人再点家具，或者把谁拎起来放到另一个人身边。

· 布置：64 款家具，8 种墙纸、6 种地板。攒够家庭基金还能扩建，最大是能住十个人的三层小楼。
· 衣橱：19 种发型、15 种上衣，另有 24 套完整形象，可以转到侧面、背面试穿。
· 小屋时光：约大家一起吃饭、围坐讲故事、开家庭音乐会，给室友过生日，跟更熟练的人学做饭。
· 月报和相册：每个月出一期小屋月报，记下表白、分手和意外插曲；一起度过的时刻会留在相册里。
· 四季：春天飘花瓣，秋天落叶，冬天下雪；春节、中秋、圣诞各有过法。

小屋的时间按自己的节奏走，现实一秒是游戏里四分钟。关掉游戏再回来，会补上离开期间发生的事（最多一个游戏日）。

单机游玩，不用联网，没有内购。进度只保存在你的设备上。

（线上 V1.0.0 的简介里这一句是「没有内购，没有广告」。带广告的版本提审时，要把后台简介里的「没有广告」去掉。）

## 广告（V1.0.1 已备好代码，广告尚未开通）

### 广告位

只有一个，激励视频，玩家自己点才播：

- **街坊赞助**：布置面板的家庭基金一行，按钮带「广告」标记。看完整段视频，家庭基金加 ¥300 / 400 / 500 / 600（跟房子等级走）；中途关掉不给；按现实日期每天最多 5 次，次数存在存档里。
- 买家具或扩建时基金不够，这个按钮会跳两下提醒，不弹窗，不自动播。
- 没有插屏、没有 Banner、没有开屏。小屋是放着看的游戏，打断式广告会直接伤体验，审核规范也只允许激励视频由玩家主动触发。

没填广告位 ID、或者不在 TapTap 里时，按钮整个不出现，游戏和 V1.0.0 完全一样。所以这份代码可以先合并，不会把一个点不动的广告按钮带上线。

代码：`js/taptap.js`（`AD_UNIT_ID`、`TapTapAds`）、`js/economy.js`（`sponsor()`）、`js/ui.js`（`renderShopBar`）。接口按官方文档 <https://developer.taptap.cn/minigameapidoc/dev/tutorial/open-capabilities/ad/rewarded-video-ad/>：`tap.createRewardedVideoAd({adUnitId})`，`onClose(res)` 里 `res.isEnded` 为真才发奖励，整个游戏只有一个实例。

页面：<https://developer.taptap.cn/v3/547547/app/1100088/operation/ad-monetization>，服务状态「待签约」。四项里完成了一项：

| 收款信息 | 未完成 | 开发者本人填财务主体和收款账户 |

查询命令（只读）：`taptap-cli mini-app-ad get-config --dev-id 547547 --app-id 1100088`。现在返回 `status: inactive`、`ad_spaces: []`。开通后会返回 `status: active` 和 `selected_space_id`，那就是广告位 ID。

### 开通之后

1. 把 `selected_space_id` 填进 `js/taptap.js` 的 `AD_UNIT_ID`。
2. `python3 build.py && python3 scripts/build-taptap.py --version 1.0.1 && node --test tests/*.test.cjs && node tests/ads-browser.cjs`。填了 ID 后，`ads-browser.cjs` 会在假的 TapTap 环境里把看完、中途关掉、没有广告、每天 5 次、存档都走一遍。
3. 上传新包、换成主包体，把后台简介里的「没有广告」去掉，提审。
4. `privacy.html` 的新文案（第四节「广告」）要和带广告的版本一起上线：把这个分支合并到 main，GitHub Pages 才会更新。生效日期改成上线那天。
5. 手机上用自测二维码点一次「街坊赞助」，确认真广告能播、看完到账。

### 没确认的事

- 后台隐私合规当时选的是「不收集用户隐私」。接了平台广告以后这一项要不要改，后台和文档里没找到说明，开通时问一下 TapTap 或看开通流程里的提示。
- 备案审核要多久。官方文档说普通小游戏的前置备案约 20 个工作日，H5 是否一样没有写明。
- 《激励协议》4.5 条写着参加期间不得自行接入商业化内容，而广告变现页又把签这份协议列为开通广告的前提。平台自己的广告位应当不算「自行接入」，但这是我的理解，签之前请自己读一遍协议。
